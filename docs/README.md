## Status Snapshot

AngleSharp.Wasm currently provides:

- Runtime registration via `WithWasm()`
- Optional host import registration via `WithWasmImports(...)`
- WebAssembly DOM surface for JS integration through discovered DOM attributes
- Module metadata APIs (`exports`, `imports`, `customSections`)
- Instance export access (`exports`) and invocation helpers

For details about supported behavior and known limitations, see:
